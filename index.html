HTTP (Hypertext Transfer Protocol)

What is HTTP?

HTTP stands for Hypertext Transfer Protocol. It allows web browsers and servers to communicate with each other.

Key HTTP Terms

  • Client: Requests information from a server.
  • Server: Responds to requests from clients.
  • Request: A message asking for information.
  • Response: A message answering a request.
