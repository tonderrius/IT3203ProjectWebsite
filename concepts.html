HTTP Key Concepts

Here are six important terms used in HTTP.

Important Terms

  • Client: A device or browser that requests information from a server.
  • Server: A computer that responds to requests from clients.
  • HTTP Request: A message sent by a client asking for information.
  • HTTP Response: A message sent by a server answering a request.
  • Status Code: A number that tells whether a request was successful or had an error.
  • URL: The address used to locate a resource on the internet.
