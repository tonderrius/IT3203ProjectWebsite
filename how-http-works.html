How HTTP Works

HTTP defines how a client and a server talk. The client sends a request naming the resource it wants, and the server replies with a response containing the content or an explanation of why it cant deliver it.

Steps of HTTP

  1. Enter a website address.
  2. The browser sends a request.
  3. The server sends a response.
  4. The browser displays the webpage.
